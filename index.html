FEATURED · AWS · TERRAFORM · PRODUCTION ARCHITECTURE

Production-Grade Three-Tier AWS Platform

Designed and deployed a reproducible three-tier web application architecture using Terraform, with 73 resources provisioned through infrastructure as code and structured around AWS Well-Architected principles.

  • Network: Multi-AZ VPC with six subnets across public, private application and private database tiers.
  • Compute: EC2 Auto Scaling Group scaling from 2–6 instances behind an Application Load Balancer.
  • Security: AWS WAFv2, IAM least privilege, Security Groups and CloudTrail auditing.
  • Database: RDS PostgreSQL 16 in private subnets with automated backups.
  • Observability: CloudWatch dashboard, six alarms and SNS notifications.
  • Storage: S3 for static assets, load-balancer logs and CloudTrail logs.
Terraform AWS VPC EC2 ALB WAFv2 RDS PostgreSQL CloudWatch CloudTrail IAM S3
